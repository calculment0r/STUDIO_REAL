Banc de mesure vidéo

Temps jusqu'à la première image, sur cet appareil. Garde l'écran allumé et cette page au premier plan pendant la mesure.

Réglages

froid : chaque répétition ajoute un paramètre aléatoire à l'adresse pour ne pas être servie par le cache du navigateur. tampon : preload=auto, puis play() seulement après canplaythrough. cache : fetch complet dans le Cache Storage (si disponible, sinon en mémoire), puis lecture depuis un blob: ; le temps de préchargement est compris dans les mesures (t_src_pose dit quand le src a été posé).

Aperçu

La vidéo doit rester visible à l'écran : un navigateur peut ne pas décoder (ni compter une « première image ») pour une vidéo cachée.

Mesures (ms)

Aucune mesure pour l'instant.

« Octets » et « réseau 1er octet » viennent de performance.getEntriesByName(src) (transferSize, responseStart). Le navigateur ne les donne que si le serveur envoie l'en-tête Timing-Allow-Origin: * quand la vidéo vient d'une autre origine ; sinon ils valent 0 ou « n/d ». Seules les requêtes terminées sont comptées, et Safari ne publie pas toujours les requêtes média.
