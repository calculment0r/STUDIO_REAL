# interdits.txt : liste de modération du spectacle ÉCHO (fil Instagram de Jim projeté sur scène), copiée de banques/interdits.txt puis adaptée.
# S'applique à TOUS les messages : figurants (N0 à N4) ET vrais spectateurs. Un message qui contient une entrée n'est pas affiché.
# Les figurants ont en plus interdits-figurants.txt (sanctions, urgences, auto-description d'IA, votes).
#
# FORMAT
#   - une entrée par ligne ; les lignes vides et celles qui commencent par « # » sont ignorées ; espaces de début et de fin retirés ;
#   - entrée simple = un mot ou une expression, écrit en FORME DE BASE NORMALISÉE : minuscules, sans accents, sans apostrophe
#     ni trait d'union (remplacés par une espace), lettres doublées légitimes gardées (« connard ») ;
#     elle correspond comme MOT ENTIER ou expression entière (bornée par le début, la fin ou une espace du texte normalisé),
#     jamais en sous-chaîne : « con » ne bloque pas « content ». Les pluriels et féminins utiles sont écrits en entrées séparées ;
#   - « re: » + expression régulière JavaScript (drapeaux « iu »), appliquée au texte en forme B (voir plus bas).
#
# NORMALISATION (faite par le serveur, pas ici ; étude modération §4.1)
#   forme A, pour les entrées simples, dans cet ordre :
#     1. Unicode NFKC ; suppression des caractères de largeur nulle et des marques de combinaison parasites ;
#     2. minuscules ; suppression des accents (é→e, ç→c, œ→oe, æ→ae) ;
#     3. homoglyphes cyrilliques et grecs ramenés au latin (table « confusables » d'Unicode) ;
#     4. leet : @→a 0→o 1→i 3→e 4→a 5→s 7→t $→s !→i (« 1 » est aussi essayé en « l ») ;
#     5. toute ponctuation (apostrophes, traits d'union, points…) → espace ; lettres isolées séparées recollées (« c o n », « c.o.n » → « con ») ;
#     6. suites de 3 lettres identiques ou plus réduites, essayées à 1 et à 2 lettres (« cooonnnard » → « conard » et « coonnard ») ;
#     7. espaces multiples réduites à une.
#   forme B, pour les motifs « re: » : étapes 1, 2, 3 et 7 seulement (PAS de leet, ponctuation et chiffres gardés),
#     pour pouvoir reconnaître liens, adresses e-mail et numéros.
#
# CHOIX
#   - Écrite pour ce prototype (pas une copie de liste existante). Point de départ possible pour la suite : LDNOOBW « fr » (CC-BY 4.0, attribution à garder).
#   - Les mots à double sens (« baiser », « peter », « queue », « pipe », « malaise »…) ne sont PAS ici : ils doivent aller en « retenir pour examen »,
#     pas en « refuser » (étude modération §4.1). Le prototype n'a pas encore cette liste.
#   - ÉCHO : section « sexisme et masculinisme » ajoutée (insultes probables vu le sujet). Les spoilers sont dans les `interdits` de chaque
#     segment (repliques.json), les noms réels cités par l'auteur dans interdits-figurants.txt. Noms réels du comédien et du lieu : à ajouter par la régie.
#   - Revue des faux positifs et des faux négatifs après chaque session ; la liste est versionnée avec le dépôt.
