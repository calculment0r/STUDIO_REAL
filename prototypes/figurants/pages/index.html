Figurants

Un comédien joue un streamer. Des figurants IA écrivent dans le chat en réagissant à ce qu'il dit. Une mini-régie les pilote.

cd STUDIO_REAL/prototypes/figurants/serveur

Puis ouvrir http://localhost:8787/prototypes/figurants/pages/. Le serveur sert la racine du dépôt, ce qui rend valides les chemins du thème (packages/theme/).

micro : contexte sécurisé obligatoire

La Web Speech API ne fonctionne que sur https:// ou http://localhost, et seulement dans Chrome sur ordinateur. Pour la page comédien, deux solutions :

# depuis un autre poste : tunnel, puis http://localhost:8787
ssh -L 8787:localhost:8787 <machine-du-serveur>

# ou en https sur le tailnet
tailscale serve --bg 8787

Sans cela, le bouton du micro reste grisé avec une explication ; le champ « dire au chat » permet de tester sans micro. Si cette page est ouverte sans serveur (fichier local, GitHub Pages), les pages affichent « serveur non joignable ».
